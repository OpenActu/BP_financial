# Avancement — les 107 modules du parcours

Un module par ligne, dans l'ordre où [`planning.md`](../../planning.md) demande de les suivre.
La colonne **Fait** se coche à la main — `[ ]` devient `[x]` quand le module est acquis,
exercices compris.

> ℹ️ **Ce fichier ne se régénère pas.** Il a été écrit une fois depuis l'arborescence ; un module
> ajouté ou renommé doit y être reporté, faute de quoi le suivi porte sur un parcours qui n'existe
> plus. Les ⭐ sont ceux des cours : les modules qui portent leur semestre.

> ℹ️ **La colonne « Durée » reste vide là où le module ne la déclare pas.** Le modèle, le canal et
> l'encadrement n'annoncent qu'un volume de cours, porté par leur titre de section — mieux vaut
> une cellule vide qu'une durée répartie au jugé.
